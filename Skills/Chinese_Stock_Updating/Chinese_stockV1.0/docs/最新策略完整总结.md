# 三、买入时机判断

## 3.1 已证伪的择时（不要用）

| 方法 | 结果 |
|:---|:---|
| 位置择时（低买高卖） | 年化 +17.5%→+14.8% 变差 |
| 相对强度择时 | 无差异 |
| MA200 趋势过滤 | 净损害 |
| 板块动量轮动 | +4.0%，不如核心仓 |

## 3.2 唯一有效的择时：估值分位

**估值分位 = 历史 PE ≤ 当前 PE 的比例（越高越贵）。**

| PE 5年分位 | 动作 |
|:---|:---|
| **> 80%（贵）** | 核心仓**减半**（卖一半转国债） |
| **< 20%（便宜）** | **恢复满仓** |
| 20%~80% | 维持不动 |

实测（上证红利 21 年）：一直持有 +5.86%/−72% → 估值择时 **+11.93%/−32%**。

# 四、止盈与止损

**不设价格止损、不设价格止盈、不做高卖低买**（都已证伪）。

| 触发 | 动作 | 本质 |
|:---|:---|:---|
| PE 分位 > 80% | 核心仓减半 | 估值过高 → 止盈 |
| PE 分位 < 20% | 恢复满仓 | 估值过低 → 加仓 |

**用估值做止盈，不用价格做止盈。**

# 六、为什么要长期持有（核心，必读）

**长期持有是这套策略成立的前提，不是可选项。**

1. 上证红利 2008 年 −72% 暴跌之后，21 年累计仍是 **+246%**——扛过暴跌，后面涨回来并创新高。
2. 若在暴跌时卖出（止损），就**锁定亏损、错过修复**。这正是"不设价格止损"的原因。
3. 核心仓收益是"分红 + 长期复利"慢慢攒出来的（银行股息 5~6%），短期看不到、长期才显现。

**一句话：短期持有 = 大概率亏在回撤里；长期持有 = 大概率赚在复利里。**
