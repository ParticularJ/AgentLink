# 一、已验证的策略（可以执行）

## 1.1 核心仓：规则化低估值高股息指数，长期持有 + 季度再平衡

> 推荐版本（30% 国债，回撤 −16.6%，贴合 10~20% 承受力）：

| 构成 | ETF | 权重 |
|:---|:---|:---|
| 银行 | 银行ETF华宝 sh512800 | 35% |
| 公用/电力 | 电力ETF广发 sz159611 | 14% |
| 煤炭 | 煤炭ETF国泰 sh515220 | 7% |
| 宽基 | 沪深300ETF华泰柏瑞 sh510300 | 14% |
| 国债 | 国债ETF国泰 sh511010 | 30% |

> 纯权益版：银行50% / 电力20% / 煤炭10% / 沪深300 20%（回撤 −25%）。

**规则**：
- 每 60 交易日再平衡回目标权重（偏离 >2~3% 才动）
- **不设价格止损、不做板块轮动、不选个股**
- 唯一择时 = 估值分位（PE 5年分位 >80% 减半、<20% 满仓）

**验证结果（8.5 年，2018-2026，跨两次熊市）**：

| 指标 | 数值 |
|:---|---:|
| 可信年化 | **≈ 6.9%**（规则化口径，无幸存者偏差） |
| 最大回撤 | −25%（加 20% 国债 → −19%） |
| 相对沪深300 | 年化高约 7pp、回撤小约 20pp |

## 1.2 为什么"无择时"（被证伪的择时）

| 择时方法 | 结果 |
|:---|:---|
| 位置择时（低买高卖） | 年化 +17.5% → +14.8%（变差） |
| 相对强度择时 | 基本无差异 |
| 沪深300 MA200 趋势过滤 | 8.5 年净损害（+9.34%→+3.24%，回撤反而扩大） |
| 板块动量轮动 | 8.5 年化 +4.0%/−31%（不如核心仓） |

**结论：所有价格/动量择时都跑不赢"一直持有"。**

## 1.3 估值分位择时（★ 有效，2026-10-17 修正方向）

> ⚠️ 重要修正：此前版本写"估值择时不能提高收益"是**百分位方向搞反了**，正确结论相反。

上证红利 21 年（2005-2026）+ 沪深300 8.8 年实测（估值分位 = 历史PE≤当前PE的比例，越高越贵）：

| 指数 | 一直持有 | 贵了卖（分位<40%） | 改善 |
|:---|---:|---:|---:|
| 上证红利 | +5.86% / −72.2% | **+11.93% / −32.3%** | 年化×2，回撤−40pp |
| 沪深300 | −0.28% / −39.9% | +5.93% / −29.6% | 转正，回撤−10pp |

**结论：「估值分位过高（贵）时减仓、过低（便宜）时持有」能同时提高收益和降低回撤。**
这是唯一被验证有效的择时（与价格/动量择时不同）。

**规则**：
| 估值分位（5年 PE 分位） | 动作 |
|:---|:---|
| > 80%（贵） | 核心仓减半，转国债 |
| < 20%（便宜） | 恢复满仓 |
| 20%~80% | 维持不动 |

## 1.4 当前估值位置（2026-10，已纠正）

| 指数 | 当前 PE | 5年分位 | 状态 |
|:---|---:|---:|:---|
| 上证红利 | 9.46 | **100%** | ⚠️ 5年内最高（因周期股盈利回落，非股价泡沫） |
| 沪深300 | 12.38 | 68% | 中性偏高 |

> 注意：上证红利"分位 100%"是**盈利回落**导致（煤/钢盈利从 2021 高点下滑），
> 绝对 PE 9.46 仍不贵。所以"贵了减仓"需结合绝对 PE 谨慎使用。

# 三、对博主观点的最终裁决

博主："长期持有优质股（低PE、强现金流）赚分红，反对抓热点赚差价。"

**数据裁决：博主是对的，而且这正是我们核心仓的哲学。**

- 核心仓 = 低估值（PE 9~12）高股息（4~6%）指数，长期持有，不择时，已验证 ✓
- 抓热点/波段 = 已证伪（动量轮动 +4.0%，板块内选股 +1.4pp，都跑不赢核心仓）✓
- "均值回归" = 有依据（我实测板块轮动长期跑输，最终回归核心仓水平）✓

**唯一需要补充的细节**：博主的"低PE买"是对的，而且**比博主说的更可操作**——
实测证明"估值分位过高（贵）时减仓、过低（便宜）时持有"能**同时提高收益和降低回撤**（上证红利年化 +5.86%→+11.93%、回撤 −72%→−32%）。
