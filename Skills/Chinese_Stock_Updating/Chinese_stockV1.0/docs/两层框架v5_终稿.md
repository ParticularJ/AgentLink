# 三、热点板块：产业基本面驱动

## 3.1 核心命题（已被两个案例支持）

> **跟踪「需求驱动的领先基本面指标」，能在价格主升浪前识别板块。**

## 3.2 正例：光模块（成立）

| 事件 | 日期 |
|:---|:---|
| ChatGPT 发布（基本面触发） | 2022-11-30 |
| 云厂商上调资本开支指引 | 2023-01~02 |
| 价格 +30%（启动） | 2023-02-07 |
| 价格 +571% | 2023-06 |

**资本开支指引领先价格约 1~2 个月。**

## 3.3 反例：造纸（证伪 + 揭示过滤条件）

造纸「反内卷 + 纸价 4230→4700」是基本面改善，但：

| 反内卷信号后 1 年 | 造纸 | 沪深300 | 光模块 |
|:---|---:|---:|---:|
| | **−2.4%** | +26.3% | +598.9% |

8 只个股 6 只下跌。**为什么失效？造纸是「供给收缩提价」，不是「需求爆发」。**

## 3.4 选板块规则（修正版）

```
1. 维护每个板块的领先基本面指标（point-in-time）
2. ★需求过滤：只做「需求驱动的量价齐升」，排除「供给收缩的温和提价」
   - 需求驱动 = 下游需求增速加速 / 新增量（新技术渗透）
   - 供给驱动 = 仅价格回升、销量未放大 → 排除
3. 拐点检测：需求指标同比增速连续 2 期由负转正 / 加速
4. 交叉验证：≥2 个需求指标同向 或 需求指标 + 价格突破
5. 建仓：板块 ETF 或龙头 Top2
6. 退出：需求指标同比增速见顶回落
```

## 3.5 板块 → 领先需求指标

| 板块 | 领先需求指标 |
|:---|:---|
| 光模块/算力 | 北美云厂商资本开支指引 |
| 半导体/存储 | DRAM/NAND 现货价、SIA 销售 |
| 造纸 | 箱板纸价 + **销量**（不是只有价格） |
| 造船 | 新船订单 |
| 油气 | 油价 + 需求 |
| 军工 | 主机厂合同负债 |
| 有色 | 库存、加工费 |
| 消费/家电 | 社零、地产竣工 |

# 五、尚未完成（数据瓶颈）

热点板块框架目前只有**光模块正例 + 造纸反例**两个案例，
系统化验证（多板块、样本外）需要 **point-in-time 基本面数据管线**：

- 云厂商资本开支 → 财报，需手动季度整理
- DRAM/NAND 现货价 → 集邦付费
- 纸价/库存 → 生意社/卓创付费
- SIA 销售 → 公开但需手动整理

**这是当前唯一的硬约束，不是策略问题，是数据可得性问题。**
