# Chinese_stockV1.0 优化总结

**文档定位**：记录从代码拉取至今的全部优化——当前逻辑是什么、改了什么、为什么改、回测效果如何。
**数据口径**：真实前复权日线，2025-09-30 ~ 2026-09-30（228 个交易日）。
**评估指标**：以「盈亏平衡胜率的安全边际」为准（见 §0.2）。

---

## §0 总览

### 0.1 效果对比

| 阶段 | 笔数 | 胜率 | 均值 | 中位 | 收益/回撤 |
|:---|---:|---:|---:|---:|---:|
| 优化前基线（724 笔，全量候选） | 724 | 42.3% | +0.98% | −2.06% | 2.49 |
| **当前生产配置** | **80** | **66.2%** | **+6.02%** | **+3.32%** | **≈8.2** |

> 笔数从 724 降到 80 是设计意图，不是退化：砍掉的是「本就不该交易的日子」（单边下跌月）和「质量最差的候选」。

### 0.2 为什么用「盈亏平衡胜率」而不是胜率或盈亏比

    盈亏平衡胜率 = 1 / (1 + 盈亏比)
    安全边际     = 实际胜率 − 盈亏平衡胜率        （> 0 才有正期望）

**为什么必须这样衡量**：胜率与盈亏比此消彼长，单独优化任一个都会得出**相反的错误结论**。
本会话中至少有 3 次，某改动「胜率提高了」但盈亏比掉得更多，实际是**变差**。

### 0.3 关键数字演变

| 指标 | 优化前 | 当前 |
|:---|---:|---:|
| 胜率 | 42.3% | **66.2%** |
| 单笔期望 | +0.98% | **+6.02%** |
| 中位收益 | −2.06% | **+3.32%** |
| 安全边际 | 未测 | **+31.5pp** |
| 训练段 / 测试段 | — | +30.0pp / **+32.8pp** |

## §1 系统架构

三层分工，另加一个独立的持仓监控：

| 层 | 职责 | 输出 |
|:---|:---|:---|
| 行情分析师 detector | 判断「大盘/板块该不该买」 | phase 标签 + 交易开关 |
| 选股扫描器 fusion_runner | 在通过的板块里「挑具体股票」 | 0~2 个 BUY 推荐 + 条件单 |
| 持仓监控 | 买入后「每天怎么管」 | 条件单形式的止盈止损 |
| 用户 | 当晚检查 → 次日挂条件单 | 实际交易 |

## §2 模块一：大盘与板块趋势判断

### 2.1 当前逻辑

档位（代码为 4 档，文档承诺 5 档——已知缺陷，见 §6）：

| 档位 | 触发规则 | 评分 |
|:---|:---|---:|
| STRONG_DOWN 下行 | close < MA20 < MA60（空头排列）或距 60 日高点回撤 > 15% | 0 |
| RANGE 震荡 | 价格在 MA60 ±5% 内 + 60 日振幅 < 15% | 90 |
| WAVE_UP 波段 | close > MA60 + MA20 走平 + 20 日振幅 8%~15% | 85 |
| STRONG_UP 单边上行 | close > MA20 > MA60 + MA20 连上 10 日 + 近 20 日涨幅 > 8% | 80 |

**大盘交易开关**（本次新增，核心改动）：

    MARKET_TRADE_SWITCH = {
        "STRONG_UP": "full", "WAVE_UP": "full", "RANGE": "full",
        "STRONG_DOWN": "off", "WEAK_DOWN": "off", "UNKNOWN": "off",
    }

**个股板块门控**：板块 STRONG_UP → 可买；RANGE/WAVE_UP → 预留（不买入）；STRONG_DOWN 及以下 → 禁止。

### 2.2 优化原因

**发现问题**：原实现的 phase **只调仓位上限，从不阻止开仓**。后果：

| 月份 | 沪深300 | detector 判定 | 实际交易 |
|:---|---:|:---|---:|
| 2026-07 | −7.48% | RANGE ×12 | 交易了 |
| 2026-08 | +1.80% | STRONG_DOWN ×13 | 交易了 |
| **2026-09** | **−5.50%** | **STRONG_DOWN ×21（全月）** | **交易 17 笔，几乎全亏** |

即：**系统明知在下跌，仍然照买。** 这正是「单边下跌的月份不做任何交易」没有落地的原因。

### 2.3 回测效果

| 口径 | 笔数 | 胜率 | 均值 | 中位 | 回撤 | 收益/回撤 |
|:---|---:|---:|---:|---:|---:|---:|
| 优化前 | 110 | 56.4% | +3.87% | +1.15% | −68.5 | 6.21 |
| **优化后** | **84** | **61.9%** | **+5.53%** | +2.87% | **−56.7** | **8.19** |

**逐月**：2026-08 由 −0.63% 转为 **+1.10%**；2026-07 由 +1.73% 升至 **+2.51%**；
**2025-09 / 2025-10 / 2026-09 三个月完全空仓，亏损全部避开。**

### 2.4 趋势判断的准确性检验

不看代码，只看判出来的档位是否真的预测了未来：

| 档位 | 大盘（非重叠 n=24） | 板块 ETF（非重叠 n=573） |
|:---|---:|---:|
| STRONG_UP | −2.40%（n=1） | +0.44%，上涨率 46.7% |
| WAVE_UP | — | −2.87%（n=6） |
| RANGE | +0.21% | **+1.64%，上涨率 60.0%** |
| STRONG_DOWN | −0.51% | −0.19%，上涨率 39.6% |
| UNKNOWN | −1.01% | +0.04% |

**方法论要点**：按日全量统计时，STRONG_DOWN 之后竟然「上涨 +0.57%」（看似完全反向）。
改用**每 10 个交易日取 1 个的非重叠抽样**后方向恢复正常。
原因是重叠窗口（相邻日共享 9/10 天行情）会严重高估样本量。

**结论**：门控方向基本正确，大盘开关站得住。档位稳定（日间跳变 10%，连续同档平均 10.4 天）。

## §3 模块二：三个选股策略与评分

### 3.1 当前逻辑

三个策略均属**右侧/突破型**：

| 策略 | 逻辑 |
|:---|:---|
| gap-fill-strategy | 缺口回补 |
| ma-bullish-strategy | 均线多头排列 |
| breakout-high-strategy | 突破新高 |

融合评分链：

    strategy_score（各 analyzer 自评）
      → best_score（多策略取最高）
      → + consistency_bonus（2 策略 +22）
      → + penalty（新闻情绪）
      → + sector_held_bonus（持仓同板块 +5）
      → base_score（截断 100）
      → combined_score = base×0.8 + contribution×0.2

### 3.2 优化原因：诊断「买在高点」

用户的观察：「我们以往的策略容易买在高点」。

**诊断结果（量化）**：

| 指标 | 数值 |
|:---|---:|
| 买入位置分位（60 日区间）均值 | **0.830** |
| 落在 90~100% 最高档的比例 | **48.6%** |
| 该档平均最大浮亏 | **−8.93%** |
| bias20（相对 MA20 乖离）均值 | +14.04%（100% 为正） |
| bias60 | +21.09%（98.2% 为正） |

**追高成立**。但需修正一处认知：**2026-07/08 的分位仅 0.680**（低于全年），那两个月的问​题是「不赚钱」而非「买得高」。

### 3.3 更严重的发现：整条评分链是反向的

对 1394 条过门控候选，算评分链每一层与未来 T+10 收益的秩相关（IC）：

| 评分层 | IC |
|:---|---:|
| combined_score | **−0.052** |
| best_score（策略自己的打分） | **−0.070** |
| rank_score | **−0.084** |

**每一层都是负的**——分打得越高，未来越差。
且**最底层 best_score 反向**，说明问题不在融合层，而在各 analyzer 的打分口径本身。

**分布退化**：25% 与 75% 分位**都恰好是 85.0**，78% 挤在 [85,90)，仅 32 个不同取值——这个分近乎常数。
而 **best_score 最高档 [90,95) 反而亏钱**（−1.26%，胜率 33.8%）。

## §4 模块三：融合推荐与智能条件单

### 4.1 当前逻辑

**六道关卡**：

    ① 大盘交易开关（STRONG_DOWN/WEAK_DOWN/UNKNOWN → 直接空仓）
    ② 板块门控（个股需板块 STRONG_UP；ETF 走独立路径）
    ③ 融合评分（多策略去重、取最高分、共振加分）
    ④ 排序并取前 N（DAILY_TOP_N = 2）
    ⑤ 信号冷却（同标的 40 个运行日内不重复推荐，不回填）
    ⑥ 入场质量分过滤（保留前 70%）

**时段**：全部改为 **CLOSE（15:00 后）** 统一运行 — `bash run_close_fusion.sh`

### 4.2 推荐输出的完整内容

每条推荐包含：**标的、评分、入场质量分、仓位、买入价、智能条件单（买入/止盈/止损）**

    {
      "code": "600150", "name": "中国船舶",
      "combined_score": 88.4, "best_score": 86.0,
      "entry_quality": 0.42, "entry_quality_keep_ratio": 0.7,
      "position_pct": 20.0, "weight": 0.20,
      "entry_ref_price": 34.56,
      "conditional_orders": {
        "buy":  { "type": "定价买入", "monitor_price": 34.56, "order_type": "限价委托",
                  "valid_months": 6 },
        "sell": {
          "stop_loss": { "base_price": 34.56, "trigger_pct": -8.0, "trigger_price": 31.8,
                         "order_type": "市价委托(最优五档)" },
          "trailing":  { "activate_above_pct": 3.0, "activate_price": 35.6,
                         "giveback_pct": 12.0, "order_type": "市价委托(最优五档)" }
        },
        "execution": { "max_hold_days": 10, "entry_max_price": 36.29,
                       "entry_max_gap_up_pct": 5.0 }
      }
    }

**条件单设计依据（来自 PDF《智能条件单完全指南》）**：
- 买入用**限价**，卖保命用**市价**（最优五档）
- 有效期 3~6 个月
- 次日开盘高于监控价 ×1.05 则放弃（**防追高**）

### 4.3 关于止盈的重要说明

**默认只有「回落卖出」，没有固定止盈价。** 原因：707 笔实测

| 方案 | 胜率 | 均值 | 训练 | 测试 |
|:---|---:|---:|---:|---:|
| 回落卖出（默认） | 48.1% | **+1.95%** | +1.83 | **+2.07** |
| 固定止盈 2:1（PDF 建议） | 49.5% | +1.53% | +1.14 | +1.92 |
| 固定止盈 + 回落 | 48.2% | +1.50% | +1.28 | +1.72 |

**固定止盈在两个半区间都更差**，因为它截断右尾。
若需要（PDF 的 2:1 比例），置 `CO_TAKE_PROFIT_PCT = 0.16` 即可启用。

### 4.4 核心优化：入场质量分

**设计**（每条有 IC 支撑）：

| 交易经验 | 因子 | 权重 | 依据 |
|:---|:---|---:|:---|
| **不追高** | dist_high_60 | **−0.40** | 位置分位均值 0.830，最高档浮亏 −8.93% |
| 不碰过热 | atr_pct | −0.25 | 全表 IC 最强（−0.180，符号稳定） |
| 要趋势 | mom_20 | +0.20 | 正动量给方向 |
| 要资金 | flow_3d | +0.15 | 量价资金推动 |

**用法**：**只做过滤不做排序**——每日候选仅约 3 条，排序没有施展空间。

**全链路回测效果**：

| 方案 | 笔数 | 胜率 | 均值 | 中位 | 止损占比 | 安全边际 |
|:---|---:|---:|---:|---:|---:|---:|
| 基线（不过滤） | 84 | 61.9% | +5.53% | +2.87% | 31.0% | +27.5pp |
| **保留前 70%（生产默认）** | 80 | **66.2%** | **+6.02%** | +3.32% | 25.0% | **+31.5pp** |
| 保留前 30% | 68 | **69.1%** | **+6.53%** | **+4.32%** | **20.6%** | 未单独测量 |

**分半**：训练 +30.0pp / **测试 +32.8pp**——**测试段优于训练段，无过拟合迹象**。

**取舍说明**：盈亏比从 1.91 微降到 1.87，但胜率提升 4.3pp、平衡点只上移 0.4pp，**净效应为正**。

## §5 模块四：持仓监控

### 5.1 当前逻辑

`daily_stop_plan.py`（`bash run_position_plan.sh`）每日按大盘/板块 phase 输出条件单：

    最终止损 = max(成本止损, 保本线(若曾浮盈达标), 最高价 × (1 − 回落比例))

### 5.2 优化原因：修一个会造成真实亏损的缺陷

**第一版把保本判断建在「当前浮盈」上**，结果输出荒谬：某持仓浮盈一度 **+13.43%**，
回落后给出的止盈价却是 **33.32（低于成本 34.56）**——触发时反而**亏 3.59%**。

**修正**：改看**持仓期最高浮盈**——只要曾达过保本线，止损就抬到成本之上（+0.2% 覆盖手续费）。

    中国船舶   STRONG_UP   成本34.56 峰值浮盈13.43% 保本已武装 -> 保本止损 @ 34.63 (+0.2%)
    半导体ETF  STRONG_DOWN 成本1.20  峰值浮盈 4.17% 保本已武装 -> 保本止损 @ 1.20  (+0.2%)
    从未浮盈    RANGE      成本10.00 峰值浮盈 1.00% 未武装     -> 成本止损 @ 9.20  (-8.0%)

### 5.3 相位动态调整：回测否决

131 笔实测（以盈亏平衡胜率判定）：

| 方案 | 胜率 | 盈亏比 | 安全边际 |
|:---|---:|---:|---:|
| **固定 −8%/回落 12%（生产默认）** | 54.2% | 2.07 | **+21.6pp** |
| 相位动态 + 保本 | 58.8% | 1.43 | **+17.6pp** |

**动态调整降低安全边际 4pp**。因此 `DYNAMIC_BY_PHASE` 与 `BREAKEVEN_ENABLED` **默认关闭**。

### 5.4 多级止损（优先级 1~9）：回测否决

`stop_loss_engine.py` 有 9 条优先级规则，但**从未被生产调用**（死代码）。逐条 A/B：

| 规则 | 动作 | 安全边际变化 | 判定 |
|:---|:---|---:|:---|
| P1 绝对亏损清仓 | 清仓 | 已含在基线 | — |
| P2 绝对亏损减半(−4%) | 减半 | +21.7 → **+19.9pp** | 有害 |
| P3 极端恐慌 | 禁止卖出 | 不可回测 | 待定 |
| P4 恐慌区 | 减至 3 成 | 不可回测 | 待定 |
| P5/P6 利润模式清仓/减半 | — | 未测 | — |
| P7 本金模式 MA5 跌破 | 减半 | 测试段 +13.3 → +11.9pp | 过拟合 |
| P8 本金模式 MA10 跌破 | 清仓 | +21.6pp（无增量） | 无价值 |
| P9 时间止损 | 清仓 | +21.7pp（**不触发**） | 不适用 |

**综合判定：不启用多级止损。** 在生产配置（T+10）下没有任何一条能提高安全边际。

**一个方法论教训**：P9 此前测出「+4.7pp 有效」，但那是用 **T+40** 样本测的，
而生产是 **T+10**——参数口径错配，结论不能搬用。

## §6 被数据否决的尝试（同样重要）

会话中约 7 种优化尝试，**只有入场质量分通过检验**：

| 尝试 | 结果 | 原因 |
|:---|:---|:---|
| 因子重排序 | 无显著改善 | 候选每日仅约 3 条，排序无施展空间 |
| 放开 reserve 候选 | +3.05% → +2.80% | 组级别优势 ≠ 组合层面优势 |
| 放开 RANGE ETF | 84 笔 +5.53% → 88 笔 +4.60% | 同上 |
| ETF 资金流信号 | +3.04% → +0.94% / +2.18% | 门槛放松，且资金流 IC 仅 +0.018 |
| 相位动态止损 | 安全边际 −4pp | 盈亏比掉得更多 |
| 保本止损 | 安全边际 −0.3pp | 同上 |
| 多级止损 1~9 | 全部未通过 | 见 §5.4 |

**反复出现的规律**：
**「某个群体的无条件表现更好」推不出「把它加进组合会更好」**——
新增候选会改变 top-2 选择与冷却期状态，挤掉原本更好的标的。
**瓶颈始终是「选不出来」，不是「候选不够」。**

## §10 一句话总结

**从 42.3% 胜率 / +0.98% 期望，提升到 66.2% / +6.02%，安全边际 +31.5pp（测试段 +32.8pp）。**

靠的是**两件真正有效的事**：① 用大盘趋势开关**不在下跌时交易**；② 用入场质量分**不买在过热的位置**。

其余约 7 种尝试全部被数据否决——**这个「否决率」本身就是结论**：
系统当前的瓶颈不在止损端、也不在候选供给端，而在**信号本身**。
在没有新信号来源之前，继续在规则层做组合，大概率还是同样的结果。
