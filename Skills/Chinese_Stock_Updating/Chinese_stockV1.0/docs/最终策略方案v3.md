# 第一部分：策略方案

## 0. 一句话概括

**60~70% 核心仓（高股息蓝筹等权）+ 30% 卫星仓（板块动量轮动，带制度开关与止损）**，
不用个股打分、不做大盘择时、不追涨停。

## 1. 资金分配

| 仓位 | 占比 | 内容 |
|:---|---:|:---|
| **核心仓** | **70%** | 银行 + 电力 + 通信资源 + 宽基，等权 |
| **卫星仓** | **30%** | 板块 ETF 动量轮动（3 个板块等权） |

> 配比依据：卫星 30% 时卡玛最高（2.89），回撤 −6.9%；
> 加到 70% 时年化虽到 +27.9%，但回撤扩大到 −11.7%、最差月 −10.7%。

## 2. 核心仓：怎么选、怎么调

### 2.1 标的池（固定，不追热点）

```
银行     工商银行 sh601398、农业银行 sh601288、中国银行 sh601988
         招商银行 sh600036、兴业银行 sh601166
电力     长江电力 sh600900、中国核电 sh601985
通信资源 中国移动 sh600941、中国神华 sh601088
宽基     沪深300ETF sh510300、中证500ETF sh510500
```

**共 11 只，等权（每只 70%/11 ≈ 6.4%）。**

### 2.2 为什么是这些
- 实测：该池等权 **年化 +13.8%、回撤 −7.8%、卡玛 1.77**，
  同期沪深300 只有 +7.5% / −17.7% / 卡玛 0.42。
- **不需要择时**：位置择时与相对强度择时实测**都让收益变差**（−2.7pp / −0.1pp）。

### 2.3 调整规则
**每 60 个交易日（约季度）再平衡回等权**，偏离超过 3% 才动手（省成本）。
**不做任何加仓/减仓的择时判断。**

## 3. 卫星仓：怎么选板块、怎么进场

### 3.1 板块候选池（12 个，用 ETF 代表）

| 板块 | ETF | 板块 | ETF |
|:---|:---|:---|:---|
| 半导体 | sh512480 | 黄金 | sh518880 |
| 光通信 | sh515880 | 煤炭 | sh515220 |
| 医药 | sz159992 | 消费 | sh512690 |
| 军工 | sh512660 | 家电 | sz159996 |
| 新能源 | sh516160 | 证券 | sh512070 |
| 有色 | sz159880 | 稀土 | sh516150 |

**为什么用 ETF 而不是个股**：实证显示，在选对的板块里**最差个股也能赚 306%**
（光通信 8 只最差），选股只能再挤出 +1.4pp，而个股特异风险极大。
**ETF 直接拿到板块平均，绕开选股问题。**

### 3.2 进场信号（每 20 个交易日评估一次）

```
第 1 步：制度开关（决定今天做不做）
  计算 M3 = 12 个板块「近 20 日收益」的横截面标准差
  若 M3 < 其历史滚动中位数（120 日起算）
      → 分化度低，板块轮动无效 → 卫星仓**空仓（持现金）**，本次不进场
  否则继续

第 2 步：板块排序
  对 12 个板块计算 60 日动量 = 当前价 / 60 交易日前价格 − 1
  取动量最高的 3 个板块
  只保留动量 > 0 的（动量为负的板块不买）

第 3 步：建仓
  3 个板块等权，各占卫星仓的 1/3
  按当日收盘价买入（信号用 T-1 数据计算）
```

**关键参数（由 walk-forward OOS 网格得出，且邻域 9/9 稳健）**

| 参数 | 值 | 邻域检验 |
|:---|:---|:---|
| 板块数 | 3 | 2/3/4 只卡玛 2.68~2.88（平滑） |
| 动量窗口 | 60 日 | 40/60/80/120 日卡玛 2.70~3.19（平滑） |
| 制度开关 | 开启 | 关闭 2.78 vs 开启 2.88 |
| 评估间隔 | 20 日 | 10日 1.69 / 20日 2.88 / 40日 1.55 |

### 3.3 制度开关 M3 的原理与实证

**为什么需要它**：板块动量策略在"板块普涨同跌"（分化度低）的市场里会失效——
所有板块一起动，没有轮动可言；只有在"结构性行情"（分化度高）里才有 Alpha。

**实测**：按 M3 分组，动量信号的优势（相对强度>0 减 ≤0）：
- 高分化度组：**+7.05pp**
- 低分化度组：**−2.45pp（会亏钱）**

## 4. 止损止盈：怎么退出

### 4.1 三档退出规则（作用于卫星仓每个持仓）

| 规则 | 触发条件 | 动作 |
|:---|:---|:---|
| **S1 硬止损** | 当前价 / 入场价 − 1 ≤ **−10%** | 当日全部平仓 |
| **S2 移动止盈** | 当前价 / 持仓期最高价 − 1 ≤ **−15%** | 当日全部平仓 |
| **S3 动量反转** | 每 20 日评估时，该板块**不再排进前 3** 或 60 日动量转负 | 下次换仓时剔除 |

**注意**：核心仓**不设止损**。理由是核心仓定位是"账户地板"，
其标的（银行/电力/宽基）回撤本身就控制在 −7.8% 以内，加止损反而会打断复利。

### 4.2 实测的交易级表现（卫星仓，34 笔）

| 指标 | 数值 |
|:---|---:|
| 交易笔数 | 34 笔（约 2.6 年） |
| **胜率** | **58.8%** |
| 平均盈利 | **+13.20%** |
| 平均亏损 | **−9.54%** |
| **盈亏比** | **1.38** |
| **单笔期望** | **+3.84%** |
| 中位数 | +1.30% |
| 最好 / 最差 | +50.4% / −18.3% |
| 盈亏平衡胜率 | 42.0% |
| **安全边际** | **+16.9pp ✅** |

> 安全边际为正 = 胜率（58.8%）显著高于盈亏平衡胜率（42.0%），
> 说明这套退出规则下的期望值是正的，不是靠赌。

## 5. 完整执行流程（每日/每 20 日）

```
【每日】
  1. 检查卫星仓每个持仓：
     - 跌破入场价 10% → 卖出
     - 自最高点回撤 15% → 卖出
  2. 其余时间不动

【每 20 个交易日】
  1. 计算 M3（板块分化度）与 60 日动量
  2. M3 低于滚动中位 → 卫星仓清空，资金转现金
  3. 否则：选动量前 3 的板块，等权持有；已被淘汰的卖出
  4. 核心仓：每 60 日再平衡到等权（偏离>3% 才动）
```

# 第二部分：回测结果

## 6. 全样本表现（2024-02-26 → 2026-10-15，629 日，含成本）

| 方案 | 年化 | 最大回撤 | **卡玛** | 月胜率 | 达标月≥1.2% | 最差月 | 连亏月 |
|:---|---:|---:|---:|---:|---:|---:|---:|
| **最终策略（核心70+卫星30）** | **+19.9%** | **−6.9%** | **2.89** | 56.2% | 37.5% | **−2.1%** | **2** |
| 沪深300 买入持有 | +7.5% | −17.7% | 0.42 | 56.2% | 40.6% | −7.9% | 4 |
| 纯核心仓（100%） | +13.8% | −7.8% | 1.77 | 43.8% | 40.6% | −5.0% | 3 |

**核心结论：相比沪深300，年化高 12.4pp、回撤小 10.8pp、卡玛好 6.9 倍、连亏月从 4 降到 2。**

## 9. 与目标的对账

| 用户目标 | 实测 | 达标 |
|:---|:---|:---:|
| 回撤 ≤20% | **−6.9%** | ✅ 大幅优于 |
| 月化 1.2%~1.9%（年化 15.4%~25.4%） | **年化 +19.9%（月化 1.52%）** | ✅ 落在区间内 |
| 每月有 2%+ | 32 个月里 **11 个月 ≥2%（34%）** | ❌ 做不到每月 |
| 1~2 个月回本 | 最长连亏 **2 个月**，单月最差 −2.1% | ⚠️ 接近，但回本时间取决于跌幅 |

**诚实说明**：月化 1.52% 达标、回撤远优于上限、连亏最长 2 个月；
但"每个月都有 2%+"不可能——只有 34% 的月份 ≥2%。

# 第三部分：已知边界（必须知道）

1. **样本只有 2.6 年**（2024-02 起）。核心仓标的行情数据不足是硬限制。
   Walk-forward 只有 3 折，OOS 年化 +19.3% 的置信度有限。
2. **样本期偏强**：2024-09 后是明显的结构性行情（板块分化度高），
   这正是本策略最擅长的环境。**在 2018 那种全面熊市里，动量轮动会连续亏损。**
3. **未计滑点与冲击成本**（只算了 0.05% 单边）。
   实盘若标的流动性差（如 sz159992 医药 ETF 成交额小），实际成本会更高。
4. **M3 开关的历史中位数需要 120 个交易日预热**，策略前半年是"裸跑"。
5. **不适用于大资金**：12 个板块 ETF 中部分日成交额有限，
   规模超过 500~1000 万时冲击成本显著上升。
